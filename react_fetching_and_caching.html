3. Fetch API

fetch() is a Web API that initiates an asynchronous HTTP request and returns a Promise<Response>.

Step 2

5. async/await

async/await is another way to write Promise-based code. The notes describe await as waiting for the Promise inside the current async function without blocking the browser's main thread.

Promise style

fetch(url)
  .then(response => response.json())
  .then(data => console.log(data));

async/await style

async function getData() {
  const response = await fetch(url);
  const data = await response.json();
  console.log(data);
}
Remember: await means “wait for this Promise to finish” inside the async function; it does not block the entire browser.

Error handling

try {
  // request
}
catch(error) {
  // error
}

6. What is a Response?

The response variable is a Response object, not the actual JSON object.

response.status

HTTP status information.

True for successful HTTP status responses such as 200.

response.headers

Response header information.

response.body

Response body stream.

Practical rule from the notes: Check response.ok before treating the response as successful data.

7. Complete React Fetching Example

The source combines useEffect, fetch, async/await, response.ok, JSON parsing, loading, success, and error handling.

import { useEffect, useState } from "react";

function App() {
  const [post, setPost] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function getPost() {
      try {
        const response =
          await fetch("https://jsonplaceholder.typicode.com/posts/1");

        if (!response.ok) {
          throw new Error("Failed to fetch data");
        }

        const data = await response.json();
        setPost(data);
      }
      catch (error) {
        setError(error.message);
      }
      finally {
        setLoading(false);
      }
    }

    getPost();
  }, []);

  if (loading) return <h2>Loading...</h2>;
  if (error) return <h2>Error: {error}</h2>;

  return (
    <div>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </div>
  );
}

export default App;

11. localStorage

The source identifies localStorage as a Web Storage API that stores key-value pairs in the browser.

  • Data remains after page refresh.
  • It can remain after reopening the browser for the same origin.
  • It is useful for small browser-side cached values.
// Store
localStorage.setItem("name", "Avinash");

// Read
const name = localStorage.getItem("name");

// Remove
localStorage.removeItem("name");

// Clear everything
localStorage.clear();

12. Caching Objects

localStorage stores strings. To store an object, convert it with JSON.stringify(), and use JSON.parse() when retrieving it.

Five things to remember from the source:
  1. fetch() gets data from an API.
  2. async/await makes Promise code easier to read.
  3. useEffect() is commonly used for fetching initial data.
  4. useState() stores fetched data and loading/error state.
  5. localStorage stores small browser-side data and can be used for caching.
