Custom Modules

Learn how to create your own reusable Node.js modules, export functions, and use them from other files.

1. What is a Custom Module?

A custom module is a user-defined module containing reusable code such as functions, objects, or classes. Other parts of a Node.js application can use that code.

🧒 ELI10: Think of a module as a small toolbox. You put useful tools inside it, label the toolbox, and another program can take the tools it needs.

Why use custom modules?

  • Organize code across multiple files.
  • Reuse functions, objects, or classes.
  • Improve maintainability and readability.
  • Make an application more modular.

Core idea

Custom Module→ Define code→ Export→ require()→ Reuse

3. Exporting Code

Defining a function is not enough. To make it available to another file, export it.

Using module.exports

// math-utils.js
"kw">function add(a, b) {
  "kw">return a + b;
}

"kw">function multiply(a, b) {
  "kw">return a * b;
}

module.exports = {
  add,
  multiply
};

Using exports

"kw">function add(a, b) {
  "kw">return a + b;
}

"kw">function multiply(a, b) {
  "kw">return a * b;
}

exports.add = add;
exports.multiply = multiply;
✍️ Remember: Both approaches export add and multiply, so another file can access them with require().

4. Importing and Using a Custom Module

🧠 Visualize it: math-utils.js is the toolbox. arthmetic.js opens that toolbox using require('./math-utils') and uses its tools.

5. Organizing Code into Multiple Modules

As an application becomes larger, separating functionality into different modules can improve clarity and maintainability. Each module should handle a specific functionality.

math application ├── addition.js → add() ├── multiplication.js → multiply() ├── division.js → divide() ├── subtraction.js → subtract() └── arithmetic.js → loads and uses the modules
