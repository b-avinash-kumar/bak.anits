How to Use This Resource

The source describes JSX as an XML-based syntax extension to JavaScript. It lets developers use HTML-like tags inside JavaScript while still using JavaScript expressions for dynamic values. JSX is not HTML; a transpiler converts it into browser-readable JavaScript during the build process.

4. JavaScript Expressions in JSX

Curly braces tell JSX to evaluate a JavaScript expression instead of treating the content as literal text.

Can use

Variables, arithmetic, function calls, logical operations and conditional expressions.

Cannot place directly

Statements such as if and for do not produce a value. Prepare complex logic before return.

const total = price * quantity;
return <p>Total: ₹{total}</p>;

6. JSX Comments

JSX comments are JavaScript comments placed inside a JSX expression container. HTML comment syntax is not valid inside a component's returned JSX.

return (
  <div>
    {/* This note is visible only in source code. */}
    <h1>Dashboard</h1>
  </div>
);

7. Conditional Rendering in JSX

Conditional rendering means displaying different UI based on data. The source presents three common approaches: prepare an element variable with if/else, use logical AND for optional content, or use a ternary for two alternatives.

{isSubmitted && <p>Submitted successfully.</p>}

{isPaid ? <Receipt /> : <PayNowButton />}

8. Rendering Lists with map() and Keys

JavaScript arrays are often converted into repeated JSX using map(). Each sibling produced by map() should have a stable key. The source recommends a database ID as a better key than an array index when items can change.

items.map(item => (
  <li key={item.id}>{item.name}</li>
))

      9. Children & Component Composition

      10. React Fragments

      A component must return one top-level value, but adding a meaningless div only to satisfy that rule can make the DOM larger. A Fragment groups multiple elements without adding an HTML element to the browser DOM.

      return (
  <>
    <h1>Title</h1>
    <p>Description</p>
  </>
);

      Table rows without an extra div

      JSXMarkup syntax
      PropsComponent input

      Mapped fragments

      import { Fragment } from "react";

function App() {
  const facts = [
    { id: 1, label: "JSX", value: "Readable UI syntax" },
    { id: 2, label: "Babel", value: "Transpilation tool" }
  ];

  return (
    <dl>
      {facts.map(fact => (
        <Fragment key={fact.id}>
          <dt>{fact.label}</dt>
          <dd>{fact.value}</dd>
        </Fragment>
      ))}
    </dl>
  );
}
      Pitfall: shorthand <>...</> cannot receive a key when mapping multiple sibling elements. Use the explicit Fragment form when a key is required.

      11. JSX & HTML Forms

      JSX uses normal form elements, but attributes follow JSX naming rules. A label connects to an input through htmlFor and id. A button inside a form defaults to submit behavior unless its type is specified.

      <form onSubmit={handleSubmit}>
  <label htmlFor="email">Email</label>
  <input id="email" name="email" type="email" />
  <button type="submit">Send</button>
</form>

      Accessible registration form

      Try submitting with the name left empty to see browser validation.

      Checkbox and boolean attribute

      Common mistakes: use defaultChecked for an initial uncontrolled checkbox, use defaultValue/value on select, and do not forget type="button" for a non-submit button inside a form.

      12. A Complete JSX Mini-Project

      The source combines expressions, attributes, conditional rendering, lists, children and fragments into a small student dashboard that can be extended one feature at a time.

      import { Fragment } from "react";

function StatusBadge({ active }) {
  return <span>{active ? "Active" : "Completed"}</span>;
}

function StudyCard({ course }) {
  return (
    <article style={{ border: "1px solid #ccc", padding: 12, margin: 8 }}>
      <h2>{course.title}</h2>
      <p>Instructor: {course.instructor}</p>
      <StatusBadge active={!course.completed} />
      {course.completed && <p>Certificate available.</p>}
    </article>
  );
}

function App() {
  const courses = [
    { id: 1, title: "JSX Foundations", instructor: "Dr. Meera", completed: true },
    { id: 2, title: "React Components", instructor: "Mr. Arjun", completed: false }
  ];

  return (
    <>
      <header>
        <h1>Student Learning Dashboard</h1>
        <p>{courses.length} courses assigned</p>
      </header>

      <main>
        {courses.map(course => (
          <Fragment key={course.id}>
            <StudyCard course={course} />
          </Fragment>
        ))}
      </main>
    </>
  );
}

export default App;

      13. Debugging Checklist

      Unexpected token

      Check for a missing closing tag, parenthesis, brace or quote.

      Adjacent JSX elements

      Wrap siblings in a semantic element or Fragment.

      Object error

      Render a property such as object.name rather than the whole object.

      Unknown prop

      Check camelCase names such as tabIndex, readOnly and onClick.

      Missing key

      Add a stable key to the outermost mapped element.

      Blank page

      Inspect the browser console and terminal for the first error, not the last cascade of errors.

      No hot reload

      Save the file, confirm the correct project folder, and restart npm run dev if needed.
