Routing means connecting a URL with a particular page or component.

3. Basic Routing

Use BrowserRouter, Routes, and Route to create pages.

import {
  BrowserRouter,
  Routes,
  Route
} from "react-router-dom";

function Home() {
  return <h1>Home</h1>;
}

function About() {
  return <h1>About</h1>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

4. Navigation with Link

Use Link to move between pages without reloading.

import { Link } from "react-router-dom";

function Navigation() {
  return (
    <nav>
      <Link to="/">Home</Link>
      <Link to="/about">About</Link>
    </nav>
  );
}

Link concept

Choose a link.
Source rule: Do not use <a href="..."> for internal React pages in this lesson. Use Link.

5. Active Link with NavLink

NavLink adds an active-state class when the link is active.

import { NavLink } from "react-router-dom";

function Menu() {
  return (
    <nav>
      <NavLink
        to="/"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        Home
      </NavLink>

      <NavLink
        to="/about"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        About
      </NavLink>
    </nav>
  );
}
.active {
  color: red;
  font-weight: bold;
}

6. Page Not Found — Fallback Route

Use path="*" for unknown URLs.

function NotFound() {
  return <h1>Page Not Found</h1>;
}

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="*" element={<NotFound />} />
</Routes>

7. URL Parameters

Use :paramName in the path and useParams() to read it.

import { useParams } from "react-router-dom";

function Student() {
  const { id } = useParams();
  return <h1>Student {id}</h1>;
}

<Routes>
  <Route
    path="/students/:id"
    element={<Student />}
  />
</Routes>

Interactive URL parameter

URL: /students/101 → Student 101
The source also presents a route with two parameters: /students/:id/:name, where both values are read with useParams().

8. Query Strings

Query strings look like /courses?branch=CSE. Use useSearchParams() to read them.

import { useSearchParams } from "react-router-dom";

function Courses() {
  const [params] = useSearchParams();
  const branch = params.get("branch") || "All";
  return <h1>Branch: {branch}</h1>;
}

9. Nested Routes and Outlet

Use nested routes when pages share a layout. The child route appears where the parent renders <Outlet />.

function DashboardLayout() {
  return (
    <div>
      <h1>Dashboard</h1>

      <nav>
        <NavLink to="/dashboard">Overview</NavLink>
        <NavLink to="/dashboard/reports">Reports</NavLink>
      </nav>

      <hr />
      <Outlet />
    </div>
  );
}

Complete nested route structure

<Route path="/dashboard" element={<DashboardLayout />}>
  <Route index element={<Overview />} />
  <Route path="reports" element={<Reports />} />
</Route>
Think of Outlet as a placeholder: the parent layout stays on screen while the matched child component appears inside the <Outlet />.

11. Quick Reference

BrowserRouterProvides routing context to the React app.
RoutesContains the route definitions.
RouteConnects a path to an element.
LinkInternal navigation without a full reload.
NavLinkNavigation link that can receive active styling.
path="*"Fallback route for unknown URLs.
useParams()Reads URL parameters such as :id.
useSearchParams()Reads query-string values.
OutletRenders the matched child route inside a parent layout.
Installation reminder: The actual React examples in the source require the react-router-dom package in a React project.
