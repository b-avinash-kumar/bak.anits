1. What is an Event?

An event is an action or occurrence performed by a user for which a program can respond.

Click

A student clicks a button.

Typing

A learner types into a search box.

Form

A student submits a form.

Pointer / Keyboard

The pointer moves or a key is pressed.

React idea: Assign a function to an event prop such as onClick or onChange. The component declares the response instead of manually attaching DOM listeners.
<button onClick={handleClick}>Mark present</button>
<input onChange={handleChange} />
<form onSubmit={handleSubmit}>...</form>

2. Syntax for React Events

React event names use camelCase, unlike HTML’s lowercase event attributes.

Use this in ReactNot this HTML-style spelling
onClickonclick
onMouseEnteronmouseenter
onKeyDownonkeydown
Important: The event prop value must be a function or an expression that produces a function. Do not call the handler while rendering.
function handleClick(event) {
  console.log(event.type);
}

<button type="button" onClick={handleClick}>Save</button>

3. Event Handlers

Named handlers inside a component

export default function App() {
  function downloadNotes() {
    console.log('Notes download started');
  }

  function openHelp() {
    console.log('Help opened');
  }

  return (
    <>
      <button onClick={downloadNotes}>Download notes</button>
      <button onClick={openHelp}>Open help</button>
    </>
  );
}

Each button can have its own named handler.

Interactive notice: multiple event types

Interactive notice

Move over or focus the card

import { useState } from 'react';

export default function App() {
  const [status, setStatus] = useState('Move over or focus the card');

  return (
    <article
      tabIndex="0"
      onMouseEnter={() => setStatus('Pointer entered')}
      onFocus={() => setStatus('Card focused')}
      onKeyDown={e => setStatus(`Key: ${e.key}`)}
    >
      <h2>Interactive notice</h2>
      <p>{status}</p>
    </article>
  );
}
Event flow: Event → Handler → State changes → UI changes.

4. The Event Object

React passes an event object to a handler when an event occurs. It contains useful information about what happened.

event.type

The event type, such as change or click.

event.target

The element that actually triggered the event.

event.currentTarget

The element whose handler is currently running.

event.key

The key value for keyboard events.

event.target.value

The current text/value for form inputs.

7. Event Propagation & preventDefault

In bubbling, an event starts at the target and then moves upward through ancestors, so both a button and its parent may respond.

stopPropagation()

Use it when the parent must not receive the event from the inner control.

preventDefault()

Use it when React should manage an action instead of allowing the browser's default action.

Propagation demo

React Foundations

Click the card to open it. The inner button can stop the event from reaching the card.

No action yet.
function openCard() {
  alert('Card opened');
}

function addBookmark(event) {
  event.stopPropagation();
  alert('Bookmarked');
}

return (
  <article onClick={openCard}>
    <h2>React Foundations</h2>

  </article>

Prevent a form reload

The page will stay in place when you submit.
function handleSubmit(event) {
  event.preventDefault();
  setNotice('Notice submitted without reloading the page');
}
Common pitfall: A button inside a form defaults to submit. Use type="button" for non-submit buttons.

8. Passing Data to Handlers

Sometimes a handler needs an extra value such as a student ID, product ID or assignment ID. Use an arrow wrapper or bind to pass that value. Do not invoke the handler during rendering.

<button onClick={() => deleteItem(item.id)}>Delete</button>

<button onClick={handleDelete.bind(null, item.id)}>Delete</button>

    9. Events in Function Components & Controlled Inputs

    Function components define event handlers as ordinary JavaScript functions inside the component. They can read props, call state setters and use the event object.

    Searching for: all students
    import { useState } from 'react';

function App() {
  const [query, setQuery] = useState('');

  function handleChange(event) {
    setQuery(event.target.value);
  }

  return (
    <>
      <label htmlFor="q">Search</label>
      <input id="q" value={query} onChange={handleChange} />
      <p>Searching for: {query || 'all students'}</p>
    </>
  );
}

export default App;
    Good practice from the source: Keep handlers short, move reusable logic into clearly named functions, and use memoization only after measuring a real performance issue.

    10. Events in Class Components

    Class components handle events through methods. A method passed directly to a child can lose its this context because it may be invoked as a plain function.

    Class handler with bind

    import { Component } from 'react';

export default class App extends Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
    this.handleClick = this.handleClick.bind(this);
  }

  handleClick() {
    this.setState(previous => ({
      count: previous.count + 1
    }));
  }

  render() {
    return (
      <>
        <p>Clicks: {this.state.count}</p>
        <button onClick={this.handleClick}>Add click</button>
      </>
    );
  }
}

    Quick Revision

    Event

    An action or occurrence that a program can respond to.

    Handler

    A function React calls when the event occurs.

    Event object

    Carries details such as type, target, key and form values.

    Propagation

    Bubbling lets the event move from target to ancestors.

    preventDefault()

    Stops the browser's default action when React should handle it.

    stopPropagation()

    Stops the event from reaching an ancestor handler.
